# Tech Stack Audit

`tech-stack-audit` is an LLM skill for technical front-end audits. It drives any browser-control tool to inspect a website's martech stack across several page types. The result is a single self-contained HTML report: Architecture diagram, top-line findings, tools by category, tool or category deep dive, and sources.

## Usage

Ask the agent to audit a site's tech stack, giving a URL and optionally a tool or martech category to focus on. The report is saved wherever the agent puts files for the user.
